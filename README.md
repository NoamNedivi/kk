# Keys Treasure Quest

A 3D browser game set in the Florida Keys. Pilot an airboat through the mangroves, seagrass flats and reef, scuba dive at flagged sites, and collect the four pieces of a pirate treasure map. Along the way: explore three bonus pirate shipwrecks, solve six riddle clues that lead to treasures hidden near landmarks, and fill a field journal with 41 species from each ecosystem.

Open `index.html` in a browser to play (it needs `game.js` and `three.min.js` beside it).

Controls: WASD / arrow keys (or drag on a touch screen), Space for actions, J for the journal, C for the treasure clues.

Built with JavaScript and [Three.js](https://threejs.org) (MIT licence, see `three.LICENSE`).
