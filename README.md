# Keys Treasure Quest

A 3D pirate game set in the Florida Keys. You captain a pirate sloop: fight rival pirate ships with broadside cannons and take the treasure they drop, scuba dive at flagged sites to collect the four pieces of a treasure map, and sink the boss ship that guards the final hoard. Side adventures: five pirate shipwrecks to dive, ten riddle clues leading to treasures hidden near landmarks, and a field journal of 57 species from each ecosystem.

Open `index.html` in a browser to play (it needs `game.js` and `three.min.js` beside it).

Controls: A/D or left/right to steer and W/S or up/down for more or less sail (or drag on a touch screen), F to fire a broadside, Space for actions (it also fires when there is nothing to interact with), M for the map, J for the journal, C for the treasure clues, V to switch between the chase camera and a top-down view.

The game simulates wind (shifting trade winds with gusts), wind-driven ocean waves that flatten over shallow water, buoyancy, sail drive and drag, ballistic cannonballs, and underwater pressure, wave surge and light absorption.

Built with JavaScript and [Three.js](https://threejs.org) (MIT licence, see `three.LICENSE`).
