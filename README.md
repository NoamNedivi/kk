# Keys Treasure Quest

A browser game set in the Florida Keys. Pilot an airboat through the mangroves, seagrass flats and reef, scuba dive at flagged sites, and collect the four pieces of a pirate treasure map while filling a field journal with the wildlife of each ecosystem.

Open `index.html` in a browser to play. Controls: WASD / arrow keys (or drag on a touch screen), Space for actions, J for the journal.
